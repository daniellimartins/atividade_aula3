# 🎨 Análise de Design e UX

## 📌 Introdução

Nesta atividade serão analisados dois sites com diferentes características de design e experiência do usuário.

O objetivo é identificar como os princípios de **harmonia visual, contraste, hierarquia tipográfica, paleta de cores, organização e usabilidade** podem influenciar a experiência de quem acessa um site.

## 🎯 Objetivo da análise

A comparação dos dois sites permite compreender a importância dos princípios de **UI/UX** no desenvolvimento de páginas web.

Um bom design deve facilitar a interação do usuário, apresentar informações de maneira clara e utilizar cores, fontes, espaços e elementos visuais de forma equilibrada.

Já um design inadequado pode causar **confusão, dificuldade de leitura, poluição visual e uma experiência negativa para o usuário**.
